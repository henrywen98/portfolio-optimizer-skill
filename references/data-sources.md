# 数据源 / 代码格式 / 排错

portfolio-optimizer 支持美股 (US)、A股 (CN)、港股 (HK) 三市场，全部走免费数据，**无需 API key**。
本文档讲清楚：代码怎么写、数据从哪来、抓不到时怎么查。

实现见 `portfolio_engine/markets.py`（代码识别与转换）和 `portfolio_engine/data.py`（多源抓取）。

## 1. 三市场代码格式

| 市场 | 写法示例 | 规则 | 可选后缀 |
|------|----------|------|----------|
| **US 美股** | `AAPL` `MSFT` `BRK-B` | yfinance 原生写法；class share 用连字符 `-`（`BRK.B` → `BRK-B`） | `.US` `.N` `.O` |
| **CN A股** | `600519` `688981` `000858` `300750` | 6 位数字。`5/6/9` 开头=上交所（含科创板 688、B股 900），其余 `0/3/2`=深交所（含创业板 300、B股 200） | `.SS`/`.SH`(沪) `.SZ`(深) `.BJ`(北交所) |
| **HK 港股** | `00700` `0700` `09988` | 4–5 位数字，前导零可省（内部按需补到 4 或 5 位） | `.HK` |

### 自动识别规则（`detect_market`，按优先级）

1. **显式后缀优先**：`.SS/.SH/.SZ/.BJ`→CN，`.HK`→HK，`.US/.N/.O`→US。
2. 纯 **6 位数字** → A股 (CN)。
3. 纯 **4–5 位数字** → 港股 (HK)。
4. 其余（**含字母**）→ 美股 (US)。

数字代码本身有歧义（无法 100% 准确）。**有歧义时用 `--market US|CN|HK` 或带后缀显式指定**，例如 `00700.HK`、`600519.SS`。整批标的同属一个市场时，直接 `--market` 最省心。

## 2. 数据源与回退（auto 模式）

`--source auto`（默认）按市场选源并逐级回退，任一源拿到数据即停：

| 市场 | 回退顺序 |
|------|----------|
| **US** | yfinance → akshare → 东财直连 |
| **CN / HK** | akshare → 东财直连 → yfinance |

- **CSV 永远是最终兜底**（`--csv`，见第 4 节），可跨任何市场。
- akshare / 东财直连底层都是东方财富（akshare 还兼新浪），无 key，**受限网络也常能通**。
- 东财直连只依赖 `requests`，akshare 没装时仍可工作；三大市场通用。
- 缺失的可选依赖（yfinance / akshare / requests）对应数据源会自动跳过，不报错。

强制单一源：`--source yfinance | akshare | eastmoney`（跳过回退，便于定位问题）。

## 3. 复权 `--adjust`

| 值 | 含义 |
|----|------|
| `qfq` | 前复权（**默认**） |
| `hfq` | 后复权 |
| `""`（空串） | 不复权 |

对 akshare 的 A股/港股、东财直连三市场均生效；yfinance 走 `auto_adjust=True`（等价于已复权）。

## 4. CSV 格式（`--csv`）

**宽表**：第一列是日期，其余每列是一只标的的收盘价，**列名即代码**。

```csv
date,AAPL,MSFT,600519
2024-01-02,185.6,370.9,1685.0
2024-01-03,184.2,368.8,1690.5
```

- 缺省取第一列为日期列。
- 配 `--tickers AAPL,600519` 只取部分列（列名必须能对上，否则报错并列出可用列）。
- 读入后前向填充再丢弃仍缺失的行。

## 5. 排错清单

| 现象 | 原因 / 处理 |
|------|-------------|
| yfinance `HTTP 429` 限流 | 数据中心 IP（云主机/CI）常被 Yahoo 限流；家用/办公 IP 通常正常。auto 模式会自动回退到 akshare/东财，无需手动处理；也可直接 `--source eastmoney` 绕开 |
| 「未能获取任何价格数据」 | 多半是**代码格式错**（如 A股漏位、港股写成 6 位、美股 class share 用了 `.` 没用 `-`）。先确认代码，再加 `--market` 或后缀显式指定 |
| 「价格数据对齐后为空」 | 各标的交易日重叠不足 → **时间窗太短**，或标的**停牌/退市/上市晚**。拉长窗口或换标的 |
| 单只标的被跳过 | 该标的所有源都没返回（停牌/退市/代码错），其余标的照常计算，日志会列出被跳过的代码 |
| 数据量太少、结果不稳 | 建议至少 **30+ 个交易日、≥2 只标的**；样本太短协方差估计不可靠 |
| 受限网络拿不到美股 | 东财后端对美股+A股+港股都稳、连受限网络也通；`--source eastmoney` 优先尝试 |

**最稳的兜底组合**：网络/源都不可靠时，自备 CSV 宽表走 `--csv`，完全离线、跨市场通用。
