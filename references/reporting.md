# 报告模板

用用户的语言写。先给方案，再给理由，最后给风险。不要开头铺垫。

## 结构

### 1. 你的情况（3-4 行）

复述关键输入，让用户确认没理解错：本金、期限、风险上限（**写明是按意愿还是按能力定的，为什么**）、已有持仓。

### 2. 建议配置

| 标的 | 代码 | 权重 | 金额 | 手数 | 作用 |
|------|------|------|------|------|------|
| | | | | | |

手数按每手 100 份和当前价折算，给出可直接下单的整数。余额单列。

### 3. 这套配置的历史表现

回测窗口 YYYY-MM-DD ~ YYYY-MM-DD（写明覆盖了哪几次下跌）：

- 年化收益 X%
- 年化标准差 X%
- **回撤：中位情形 -X%，二十分之一的概率超过 -Y%（自助 p95），百分之一的概率超过 -Z%（p99）**
- 历史实现的那一次是 -W%。**不要只报这个数**——它是单条路径的一次抽样，系统性乐观约 6 个百分点
- 夏普 X

**子区间检验**（逐段列出）。若 `breached_in_subperiod` 为 true，在这里明确警告：
「全窗口达标只是被某一段的大涨稀释了，YYYY 到 YYYY 这段实际回撤 X%，超过了你的上限。」

### 4. 多承受一点回撤能多赚多少

把 `frontier` 画成表。这是用户最该看的一张表——它把「要不要再冒险一点」变成一个有数字的选择。

| 回撤上限 | 能拿到的最高年化 |
|----------|------------------|
| 10% | X% |
| 20% | X% |
| 30% | X% |

若曲线在某处见顶后下降，直接指出来：「回撤放到 X% 以上，收益反而降了，没有必要。」

### 5. 怎么建仓

根据 WebSearch 查到的估值分位：

- 分位低（<30%）→ 可一次性建仓
- 分位中等 → 分 3-6 期，每月一次
- 分位高（>70%）→ 分 6-12 期

写明理由和具体的每期金额。

### 6. 什么时候调整

- **再平衡规则**：任一标的偏离目标权重超过 ±5 个百分点时调回；每年至少检查一次。
- **不需要调整的情况**：市场跌了、有人说要崩了、某个板块很火——这些都不是调整理由。
- **需要重做画像的情况**：收入变化、这笔钱的用途变了、期限变了。

### 7. 风险

必须包含这几条，不能省：

- **历史回撤不是未来上限。** 回测从 2014 年开始，不含 2008 年——沪深300 在 2008 年回撤过 72.3%。
  如果重演那种级别的下跌，这个组合的实际亏损会明显超过回测数字。
- **危机时相关性会一起冲向 1。** 分散效果在最需要它的时候最弱。
- **这套权重是在历史数据上选出来的**，本质上偏向过去这十几年表现好的资产。未来领先的资产可能不同。
- QDII 溢价、债券 ETF 流动性等标的层面的风险（见 `asset-menu.md`）。

### 8. 免责

> 本报告是研究和规划工具，不构成投资建议。历史回测不预示未来收益。据此操作的盈亏由本人承担。

## 写作要求

遵守 CLAUDE.md 里的中文写作规范：

- 主语写出来，不写「审核通过后调整」，写「你在季度检查时把权重调回目标」。
- 抽象词落到具体变化：不写「优化风险收益特征」，写「同样的回撤下每年多赚 2 个点」。
- 不用「值得注意的是」「总而言之」「首先其次」这类套话。
- 数字后面跟上它的含义。不写「夏普 1.06」，写「夏普 1.06（每承受 1 单位波动换来 1.06 单位超额收益）」。
